# 新年抽奖小程序使用说明

## 功能介绍

这是一个功能完整的新年抽奖小程序，支持在线扫码参与、名单管理、抽奖功能和内定奖项设置。

## 页面说明

### 1. 管理员页面 (`/`) - 仅管理员使用
- 管理员专属抽奖界面
- 显示红色"管理员模式"标签
- 可以进行抽奖操作
- 可以查看获奖名单
- 可以重置抽奖数据
- 提供快捷入口到管理后台和观众页面

### 2. 管理后台 (`/admin`) - 仅管理员使用
- 参与者管理：添加、删除、设置内定人员
- 奖项管理：添加、编辑、删除奖项
- 二维码生成：生成报名二维码供参与者扫描

### 3. 观众页面 (`/view`) - 参与者和观众使用
- 显示蓝色"观看模式"标签
- 只读模式，不能操作
- 查看统计数据
- 查看奖项列表和剩余数量
- 查看获奖名单
- 查看最新中奖结果
- 每5秒自动刷新数据

### 4. 报名页面 (`/join`) - 参与者使用
- 参与者填写姓名和手机号报名
- 报名成功后可跳转到观众页面
- 支持手机扫码直接访问

## 权限分离

系统已实现严格的权限分离：

- **管理员**：可以管理参与者、管理奖项、进行抽奖、重置数据
- **观众**：只能查看统计数据和获奖结果，不能进行任何操作
- **参与者**：只能报名参与，不能查看其他信息，不能进行抽奖

详细说明请参考 [权限分离使用指南](PERMISSION_GUIDE.md)

## 二维码地址配置

系统提供了三种二维码地址选项，确保参与者能够正常访问报名页面：

### 选项1：局域网地址（推荐）
- **用途**：同一WiFi网络内的手机扫码访问
- **格式**：`http://192.168.x.x:5000/join`
- **优点**：无需额外配置，自动获取本机IP
- **场景**：公司/家庭内网环境

### 选项2：本机地址
- **用途**：仅在本机浏览器测试使用
- **格式**：`http://localhost:5000/join`
- **限制**：手机无法访问（因为是localhost）
- **场景**：开发测试

### 选项3：自定义地址
- **用途**：部署到公网服务器时使用
- **格式**：`http://your-domain.com:5000/join`
- **配置**：在管理后台手动输入完整URL
- **场景**：正式部署、云服务器

## 使用流程

1. **选择二维码地址**
   - 访问管理后台 `/admin`
   - 找到底部的"参与者报名二维码"区域
   - 根据实际环境选择合适的地址类型

2. **让参与者扫码**
   - 使用手机扫描显示的二维码
   - 或点击"复制链接"按钮分享链接

3. **参与者报名**
   - 扫描后自动打开报名页面
   - 填写姓名和可选的手机号
   - 提交后即可参与抽奖

## 使用流程

1. **初始化奖项**
   - 首次使用，在管理后台会自动创建默认奖项（一等奖×1、二等奖×2、三等奖×3）

2. **添加参与者**
   - 方式1：在管理后台手动添加
   - 方式2：扫描管理后台的二维码，在报名页面自行填写
   - 方式3：复制报名链接分享给参与者

3. **设置内定（可选）**
   - 在管理后台为特定人员设置内定奖项

4. **开始抽奖**
   - 在主页选择奖项，点击"开始抽奖"

5. **查看结果**
   - 右侧实时显示获奖名单（标明随机/内定）

## 常见问题

### Q: 扫描二维码后无法访问报名页面？
A: 请检查：
1. **局域网地址是否正确**：确保手机和电脑在同一WiFi网络
2. **防火墙设置**：确保5000端口未被防火墙阻止
3. **尝试测试打开**：在管理后台点击"测试打开"按钮验证链接可用
4. **使用自定义地址**：如果局域网地址不行，尝试手动输入IP地址

### Q: 手机扫码显示"无法连接"？
A: 可能的原因：
1. **网络不通**：确保手机和电脑在同一WiFi下
2. **IP地址变化**：电脑重启后IP可能变化，重新加载管理后台
3. **防火墙限制**：检查防火墙是否允许5000端口
4. **尝试手动访问**：在手机浏览器直接输入 `http://电脑IP:5000/join`

### Q: 如何查看本机IP地址？
A:
1. 打开管理后台 `/admin`
2. 查看"局域网地址"选项中显示的IP
3. 或在电脑终端运行 `ipconfig`（Windows）或 `ifconfig`（Mac/Linux）

### Q: 部署到服务器后如何配置？
A:
1. 在管理后台选择"自定义地址"
2. 输入服务器的公网IP或域名，如 `http://123.45.67.89:5000`
3. 或配置 `NEXT_PUBLIC_BASE_URL` 环境变量
4. 确保服务器防火墙开放5000端口

### Q: 如何重置抽奖？
A: 在管理后台点击"初始化"按钮，会清除所有数据并重新创建默认奖项。

### Q: 如何修改奖项？
A: 在管理后台的"奖项管理"标签页，可以编辑、删除或添加新奖项。
